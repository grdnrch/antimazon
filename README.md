# Antimazon

A lightweight Manifest V3 Chrome extension that cleans up Amazon search results:
- **Removes sponsored search results** and brand ad banners.
- **Defaults sorting to Avg. Customer Review** (`review-rank`).
- **Filters out excluded keywords** (such as `"christian"`).

## Installation (Unpacked)
1. Open Chrome and navigate to `chrome://extensions/`.
2. Enable **Developer mode** in the top-right corner.
3. Click **Load unpacked** and select this directory.
